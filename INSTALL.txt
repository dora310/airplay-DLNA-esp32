GitHub ESP-IDF matrix build fix
================================

Problem fixed
-------------
The repository's generated sdkconfig was created for ESP32-S3. Matrix jobs
that build ESP32 targets then failed because IDF_TARGET was set to esp32.

Installation
------------
1. Extract this ZIP into the root of your GitHub repository.
2. Allow these files to replace the existing files:
     .github/workflows/build.yml
     .gitignore
3. Remove any generated sdkconfig files already committed to Git:
     git rm --cached sdkconfig sdkconfig.old
   If Git says a file does not exist or is not tracked, that is safe to ignore.
4. Also delete the local build folder if it exists.
5. Commit and push the changes.
6. Open GitHub > Actions and rerun the failed workflow.

What changed
------------
Before every target build, the workflow now removes sdkconfig, sdkconfig.old,
and build/. ESP-IDF then creates a fresh configuration for the current matrix
target. The .gitignore prevents generated configurations and build output from
being committed again.

Note
----
The .github folder begins with a dot and can be hidden by Windows or archive
programs. Extract the ZIP directly into the repository root so the folder
structure is preserved.
