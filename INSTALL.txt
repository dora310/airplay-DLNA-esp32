AirPlay and DLNA Receiver v3.1.0 cumulative replacement
========================================================

Control-panel text changes
--------------------------

Top heading:

  AirPlay 2 and DLNA+ Receiver
  Configuration Panel

System Logs description:

  Live log output via WebSocket

This package also retains the earlier `AirPlay and DLNA Setup` provisioning
Wi-Fi name and the self-contained GitHub BIN workflow.

Installation
------------

1. Extract this ZIP into the ROOT of the GitHub repository.
2. Allow Windows to replace all existing files while retaining the folders.
3. Commit all changes in GitHub Desktop and push to origin.
4. Run GitHub Actions > Build ESP32-S3 installation BIN.
5. Download and install the newly generated v3.1.0 BIN artifact.

The text is stored in the SPIFFS web image, so rebuilding and flashing the new
firmware is required. The firmware version remains 3.1.0.
